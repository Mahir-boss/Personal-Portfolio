# Personal Portfolio Website — Frontend Engineering Assignment

A responsive personal portfolio website developed as **Task 1** of the Frontend Engineering course assignment. This project highlights my profile as a Software Engineering student, technical skills, and completed and ongoing projects[cite: 1].

## 🚀 Live Demo
* GitHub Repository: https://github.com/Mahir-boss

## 🛠️ Technologies Used
* **HTML5**: Semantic markup structure.
* **CSS3**: Custom styling, layout design, and smooth transitions.
* **Bootstrap 5**: Framework for responsive grids, components, and styling utilities.
* **FontAwesome**: Icons for social links and UI enhancements.

## 📂 Core Sections
* **Navbar & Hero Section**: Fixed-top navigation with smooth scrolling and an engaging introduction.
* **About Me**: Professional summary outlining my background as an Software Engineering student and career aspirations.
* **Technical Skills**: Visual progress indicators for HTML, CSS, JavaScript, and framework familiarity.
* **Featured Projects**: Responsive card grid showcasing solo and collaborative engineering projects (complete with repository links).
* **Contact Form**: Clean, interactive UI layout for user inquiries.

## 📱 Responsiveness
Designed with a mobile-first mindset using Bootstrap's fluid grid system, ensuring a seamless layout and optimal user experience across mobile phones, tablets, and desktop screens.
